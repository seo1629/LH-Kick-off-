# LH 모듈러 중형 표준평면 Kick-off

13장 HTML 발표 자료. 2026-10-19 서버 파일 기준 보관본입니다.

## 파일

- `LH_모듈러_Kickoff.html`: 편집용. 직접 글자 수정, 위치 이동, 맞춤·간격·순서 조정, GLB 불러오기 지원.
- `lh-kickoff-public/`: 편집 기능을 제거한 Vercel 배포용 정적 사이트.
- `build-lh-kickoff.cjs`: 원본 템플릿과 작성된 콘텐츠로 HTML 재생성.
- `template/`: 재생성에 필요한 독립 실행형 원본 템플릿과 라이선스.
- `과업및템플릿분석.md`: 과업과 제작 방향 기록.

## PC에서 열기

Chrome 또는 Edge로 편집용 HTML을 직접 엽니다. 별도 패키지 설치는 필요하지 않습니다. 로컬 서버를 사용할 경우 Node.js 설치 후 이 폴더에서 `node server.cjs`를 실행하고 <http://127.0.0.1:8003/>에 접속합니다. 종료는 Ctrl+C입니다.

## 수정과 저장

글자 수정 또는 위치 이동 후 **편집 → 수정본 HTML 저장**으로 파일을 내려받습니다. 브라우저에서 수정한 내용은 서버 파일이나 Git에 자동 반영되지 않습니다. 내려받은 HTML을 원하는 편집용 파일로 보관하고 Git에 반영해야 합니다.

`node build-lh-kickoff.cjs`는 코드에 정의된 내용으로 편집본과 열람본을 다시 만듭니다. 내려받은 수정본의 변경 사항을 자동 가져오지는 않으므로 재생성 전에 별도 보관하세요.

## Vercel

배포 루트는 반드시 `lh-kickoff-public` 폴더를 선택합니다. 이 폴더에는 HTML, 라이선스, Vercel 설정만 포함됩니다. 편집본·템플릿·분석 문서를 배포 루트에 함께 넣지 않습니다. 열람본에는 편집기가 없지만 복사·캡처를 막는 기능은 아닙니다.

현재 열람본은 코드 기준으로 생성된 버전입니다. 브라우저에서 저장한 최신 편집본을 배포하려면 그 파일의 내용을 반영한 열람본을 별도로 만들어야 합니다.

## GitHub

로컬 Git 저장소를 초기화했습니다. 원격 URL이 정해지면 origin 연결 후 push합니다. 실제 업로드 여부는 별도로 확인해야 합니다. 편집본과 분석 문서도 저장되므로 공개 범위를 확인하세요.
